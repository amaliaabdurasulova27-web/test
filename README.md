# Price Recommendation

Асинхронный модуль расчёта рекомендованных цен на автозапчасти на основании предложений конкурентов.

Проект выполнен в рамках тестового задания. Основной приоритет — корректность финансовых расчётов, обработка ошибок источников и предотвращение автоматического применения некорректных цен.

## Возможности

- Асинхронное получение предложений конкурентов.
- Ограничение времени ожидания источника.
- Фильтрация предложений по сроку доставки.
- Исключение собственного магазина `MYSHOP` независимо от регистра.
- Расчёт рекомендованной цены с использованием `Decimal`.
- Округление денежных значений вниз до двух знаков после запятой.
- Проверка отклонения рекомендованной цены относительно текущей.
- Разделение результатов на `APPLY`, `REVIEW` и `HOLD`.
- Автоматические тесты на основе стандартной библиотеки Python.

## Бизнес-логика

Функция `recommend_price()` принимает:

| Параметр | Описание |
|---|---|
| `fetch_offers` | Асинхронная функция получения предложений |
| `current_price` | Текущая цена товара |
| `min_price` | Минимально допустимая цена |
| `timeout_s` | Максимальное время ожидания источника, по умолчанию 2 секунды |

### Правила расчёта

**1. Получение данных**

Ожидание источника ограничено параметром `timeout_s`.

При исключении, тайм-ауте или статусе, отличном от `success`, возвращается `HOLD`.

**2. Фильтрация предложений**

Учитываются только предложения, которые соответствуют условиям:

- Продавец не является `MYSHOP` (без учёта регистра).
- Срок доставки известен.
- Срок доставки не превышает 6 дней.

**3. Проверка наличия предложений**

Если подходящих предложений нет, возвращается текущая цена и `HOLD`.

**4. Расчёт рекомендации**

Из минимальной цены подходящего конкурента вычитается 1,5%.

```python
discounted_price = (
    min_competitor_price * Decimal("0.985")
).quantize(
    Decimal("0.01"),
    rounding=ROUND_DOWN
)
```

Итоговая рекомендация не может быть ниже минимально допустимой цены:

```python
recommended_price = max(discounted_price, min_price)
```

**5. Проверка отклонения**

Относительное изменение рассчитывается относительно текущей цены:

```python
deviation = abs(
    recommended_price - current_price
) / current_price
```

Если текущая цена равна нулю, автоматическое применение запрещается и возвращается `REVIEW`.

Если отклонение строго больше 30%, возвращается `REVIEW`. В остальных случаях — `APPLY`.

### Возможные решения

| Решение | Значение |
|---|---|
| `APPLY` | Рекомендация может быть автоматически применена |
| `REVIEW` | Требуется ручная проверка |
| `HOLD` | Текущая цена сохраняется, автоматическое обновление запрещено |

## Пример работы

Исходные данные:

| Параметр | Значение |
|---|---:|
| Текущая цена | 4900.00 |
| Минимальная цена | 4500.00 |
| Цена конкурента | 4800.00 |
| Доставка | 3 дня |
| Скидка | 1.5% |

Расчёт:

```text
4800.00 × 0.985 = 4728.00

max(4728.00, 4500.00) = 4728.00

Отклонение = 3.51%

Результат = APPLY
```

## Обработка ошибок

Модуль предусматривает безопасное поведение в следующих ситуациях:

| Ситуация | Результат |
|---|---|
| Тайм-аут источника | `HOLD` |
| Исключение при получении данных | `HOLD` |
| Статус `partial` или `error` | `HOLD` |
| Нет подходящих предложений | `HOLD` |
| Отклонение больше 30% | `REVIEW` |
| Текущая цена равна нулю | `REVIEW` |

При `HOLD` возвращается текущая цена. При `REVIEW` возвращается рассчитанная рекомендация, но её автоматическое применение запрещено.
